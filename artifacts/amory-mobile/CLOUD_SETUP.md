# تفعيل الحساب السحابي في Amory V5

## 1) Supabase
1. افتح مشروع Supabase الخاص بك.
2. افتح SQL Editor.
3. انسخ محتوى `supabase-cloud.sql` وشغّله.
4. من Authentication > Providers تأكد أن Email مفعّل.
5. لو تريد دخولًا فوريًا بدون تأكيد بريد، عطّل Email Confirmations. وإلا سيصل للمستخدم رابط تأكيد بالبريد.

## 2) Vercel Environment Variables
أضف في Project Settings > Environment Variables:

- `VITE_SUPABASE_URL` = رابط مشروع Supabase
- `VITE_SUPABASE_ANON_KEY` = مفتاح anon/public الخاص بالمشروع

ثم اعمل Redeploy.

## 3) الاستخدام
- افتح التطبيق على الجهاز الأول وأنشئ حساب المحل.
- سجّل الدخول.
- الجهاز الأول يرفع بياناته الحالية إلى مساحة الحساب إذا كانت المساحة السحابية جديدة.
- افتح نفس البريد وكلمة المرور على الجهاز الثاني؛ سيحمّل نفس البيانات.
- التغييرات الجديدة تُرفع للسحابة، والأجهزة المفتوحة تستقبل التحديثات عبر Realtime.

مهم: PIN الخاص بالمستخدمين لا يتم رفعه للسحابة. هو سر محلي على الجهاز، ويمكن تعيين PIN على كل جهاز بعد تسجيل الدخول للحساب السحابي.

هذه هي المرحلة الأولى من المزامنة. النسخة الحالية تستخدم snapshot آمنًا لكل حساب مع version guard لمنع جهاز من الكتابة فوق تحديث أحدث بدون تنبيه. المرحلة التالية الأفضل هي تحويل الحركات والفواتير إلى مزامنة صف-بصف وRPCs ذرية للمخزون والخزينة.
